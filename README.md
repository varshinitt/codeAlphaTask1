# Random Quote Generator

A simple and interactive **Random Quote Generator** built using HTML, CSS, and JavaScript. The application displays a random inspirational quote along with its author whenever the user clicks the generate button.

## Features

* Displays random quotes
* Shows the quote along with the author's name
* Simple and user-friendly interface
* Interactive button using JavaScript
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Click the **Generate Quote** button to display a new quote.

## Purpose

This project was created to practice JavaScript concepts such as arrays, objects, functions, DOM manipulation, and event handling.
